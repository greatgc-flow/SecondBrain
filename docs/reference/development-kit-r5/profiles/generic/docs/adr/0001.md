# ADR-0001 Core/Extension 의존성 단방향

- 상태: ACCEPTED_FOR_TEMPLATE (실제 제품 적용은 별도 프로젝트 승인 필요)
- 결정: 도메인 불변식을 Core에, 외부 도구 구현을 adapter에 둔다
- 채택 사유: extension 장애가 Core 저장 작업을 멈추지 않도록 한다
- 비용·반례: 단일 파일로 충분한 작은 프로젝트에서는 adapter를 억지로 늘리지 않는다
- 롤백/재검토: 기능 프로파일 변화, 실제 반례/성능 근거, 인터페이스 계약 변경 시 새 ADR 작성; 기존 ID 재사용 금지.
- 연관: docs/00_NORMATIVE_AND_PRIORITY.md, docs/03_MECE_AND_TRACEABILITY.md
