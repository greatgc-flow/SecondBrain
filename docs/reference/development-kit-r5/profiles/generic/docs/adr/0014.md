# ADR-0014: Agent harness는 권한·워크스페이스·증빙에 한정

- 상태: ACCEPTED_DESIGN (Pre-TDD)
- 날짜: 2026-10-10
- 범위: 범용 패키지 공통/조건부 개발 기준

## 결정
Agent 모델은 신뢰 경계 밖의 비결정적 작업자. tool permissions, checkpoint, resume, budget은 host policy. long-run은 bounded units.

## 대안 및 포기 사유
외부 도구를 Core 필수로 넣거나 전면 자율 Agent를 허용하면 이식성·증빙·권한 경계가 무너질 위험이 크다. 선택 어댑터와 결정적 테스트 하네스를 우선한다.

## 되돌림 / 재검토
`quality/research_decisions_20261010.csv`에 기록한 재검토 트리거와 실제 성능/안전성 측정치로 변경 제안한다. 충돌하는 기존 ADR은 superseded를 명시하며 동시에 규범으로 유지하지 않는다.
