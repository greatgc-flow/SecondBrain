# MCP integration R2 (optional adapter)

No MCP dependency for filesystem Core. Local stdio initial transport, version compatibility check. Tools for read/search/context/lineage scoped by principal, sensitivity and matter/hold policy; proposals separated from mutations, raw Evidence bytes not exposed by default. `brain://` application URI mapping only. Networked server/remote auth intentionally deferred and requires fresh security review. See `docs/19_SECURITY_PRIVACY_AI.md` and `docs/25_INTEGRATION_BASELINES.md`.

정확한 protocol baseline: MCP `2026-07-28` (stateless core). https://modelcontextprotocol.io/specification/2026-07-28/ . 2025-11-25 호환 shim은 추가 결정 없이 구현하지 않는다.
