# Archived design references (read-only, NOT executable contract)

This directory preserves the **textual design/source/traceability/reference** materials previously bundled with R4 and R5 as readable Git-tracked files, without nested ZIP archives. This is history, **not a second SSOT**. In a conflict, use `README.md`, `profiles/secondbrain/*`, and GitHub CI of the current commit. R5's embedded 230 SecondBrain files were byte-for-byte identical to R4 and are represented only once here.

The legacy kit files inside `docs/reference/development-kit-r5/` are preserved as historical sources; they are **not** a supported installed CLI or executable test suite. Paths, manifests and commands referring to the original ZIP layout can be stale. New changes should be made in current code, not these archived copies.

Exclusions: source ZIP files, nested ZIPs, private evidence, temporary data, `.gitkeep` placeholders, generated package checksums, and layout-specific Git metadata. Original legacy ZIPs remain with the operator and are not a release artifact or part of source control.

See `docs/reference/SOURCE_INVENTORY.json` for exact exported paths, original sha256 and exclusion summary. This reference import makes no product implementation or certification claim.
