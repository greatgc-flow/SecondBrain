# ADR-0002 Provider 독립 인터페이스

- 상태: ACCEPTED_FOR_TEMPLATE (실제 제품 적용은 별도 프로젝트 승인 필요)
- 결정: 공개 I/F에 공급자 전용 경로/세션을 직접 넣지 않는다
- 채택 사유: 유연한 의존 교체와 계약 안정성
- 비용·반례: 실제 공급자 기능 차이는 feature negotiation
- 롤백/재검토: 기능 프로파일 변화, 실제 반례/성능 근거, 인터페이스 계약 변경 시 새 ADR 작성; 기존 ID 재사용 금지.
