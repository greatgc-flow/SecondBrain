# ADR-0012 표준 근거와 준수 주장 분리

- 상태: ACCEPTED_FOR_TEMPLATE (실제 제품 적용은 별도 프로젝트 승인 필요)
- 결정: 표준은 설계 참고; 준수 레벨은 실제 증빙만
- 채택 사유: 감사 오해 방지
- 비용·반례: 연구 및 릴리스 시점 지속 확인
- 롤백/재검토: 기능 프로파일 변화, 실제 반례/성능 근거, 인터페이스 계약 변경 시 새 ADR 작성; 기존 ID 재사용 금지.
