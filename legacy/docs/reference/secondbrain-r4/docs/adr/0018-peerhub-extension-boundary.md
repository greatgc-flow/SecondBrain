# ADR-0018 — peerhub extension boundary

Status: Accepted (R2, 2026-10-09).

## Decision
PeerHub Core=Peer/Stream/Record/Offset(2026-10-09). Second Brain bridge는 선택 Extension/API wrapper이며 SSOT/secret ownership 없음.

## Rationale / consequences
세부 구조·실패 사례·수락 기준은 `docs/15_R1_AUDIT_FINDINGS.md` 및 관련 도메인 설계 문서의 계약을 따른다. 변경은 새로운 ADR과 마이그레이션 절차를 요구한다.
